De schrijfendpoints (`PUT`/`DELETE /listings/{externalReference}`, `POST /listings/{externalReference}/status`, `POST /listings/bulk-upsert`) retourneren een object met een vaste `code` en een leesbare `message`:

```json
{
  "error": {
    "code": "FOUT_CODE",
    "message": "Leesbare beschrijving van de fout"
  }
}
```

Bij `VALIDATION_FAILED` staat er ook `issues` in (`path`, `message`, `code` per probleem), bij `RATE_LIMITED` ook `retryAt`, bij `TOO_MANY_ITEMS` ook `maxItems`.

De leesendpoints (`GET /listings`, `GET /locations`, `GET /locations/{id}/listings`) retourneren een eenvoudige tekst: `{"error": "Unauthorized"}`, `{"error": "Too many requests"}` of `{"error": "Failed to load listings"}`.

Een geslaagde aanvraag geeft altijd HTTP 200, ook bij het aanmaken van een advertentie.

## Foutcodes van de schrijfendpoints

| HTTP Status | Code | Beschrijving |
|-------------|------|--------------|
| 401 | `UNAUTHORIZED` | Ongeldige of ontbrekende API-sleutel, of geen scope `write:listings` |
| 429 | `RATE_LIMITED` | Te veel aanvragen; wacht `Retry-After` seconden |
| 400 | `INVALID_REFERENCE` | Lege referentie, of een bulk-item zonder `externalReference` |
| 400 | `INVALID_JSON` | Ongeldige JSON in de body |
| 400 | `INVALID_BODY` | De body is geen JSON-object (bulk: geen array en geen `items`) |
| 400 | `EMPTY_PAYLOAD` | Bulk: lege lijst |
| 400 | `TOO_MANY_ITEMS` | Bulk: meer dan 100 items |
| 422 | `VALIDATION_FAILED` | Een veld voldoet niet aan de regels; zie `issues` |
| 400 | `INVALID_TITLE` | `title` bevat enkel spaties |
| 400 | `INVALID_PRICE` | `status` is `active` of `pending` zonder `price` groter dan 0 |
| 400 | `INVALID_PROFILE` | Geen dealer gevonden voor `dealerProfileId` / `dealerLocationCode` |
| 403 | `PROFILE_FORBIDDEN` | De dealer is niet (meer) aan uw sleutel gekoppeld |
| 400 | `INVALID_LOCATION` | `postalCode` of `city` ontbreekt, of `province` bij een postcode die geen Belgische 4-cijferige code is |
| 404 | `NOT_FOUND` | Uw sleutel heeft geen advertentie met deze referentie (DELETE, status) |
| 409 | `REFERENCE_OWNED_BY_OTHER_DEALER` | Enkel bij sleutels voor goedgekeurde dealers: deze referentie wordt door uw sleutel al gebruikt voor een wagen van een andere dealer |
| 409 | `LISTING_LIMIT_REACHED` | De wagen zou `active` worden, maar het pakket van de dealer is vol. Er werd niets bewaard |
| 409 | `DEALER_PLAN_REQUIRED` | De wagen zou `active` worden, maar de dealer heeft geen actief pakket. Er werd niets bewaard |
| 500 | `FETCH_FAILED`, `UPSERT_FAILED` | Okasie kon de advertentie niet lezen of bewaren; probeer later opnieuw |
| 500 | `FEATURES_FAILED`, `IMAGES_FAILED` | De advertentie is bewaard, de uitrusting of foto's niet; stuur dezelfde PUT opnieuw |
| 500 | `UPDATE_FAILED` | DELETE of statuswijziging mislukt; probeer later opnieuw |

De volledige lijst met uitleg staat in het Engels op [Error Handling](/errors).

## Voorbeeld foutafhandeling

<CodeGroup>
```javascript Node.js
async function apiCall(endpoint, options = {}) {
  const response = await fetch(
    `https://www.okasie.be/api/external/v1${endpoint}`,
    {
      ...options,
      headers: {
        'Authorization': `Bearer ${process.env.PARTNER_SECRET}`,
        'Content-Type': 'application/json',
        ...options.headers
      }
    }
  );

  const data = await response.json();

  if (!response.ok) {
    const error = data.error || data;
    switch (error.code) {
      case 'RATE_LIMITED':
        // Wacht en probeer opnieuw
        await sleep(60000);
        return apiCall(endpoint, options);

      case 'VALIDATION_FAILED':
        console.error('Validatiefouten:', error.issues);
        throw new Error(`Validatie mislukt: ${error.message}`);

      default:
        throw new Error(`API fout: ${error.code} - ${error.message}`);
    }
  }

  return data;
}
```

```python Python
import time

def api_call(endpoint, method="GET", data=None):
    response = requests.request(
        method,
        f"https://www.okasie.be/api/external/v1{endpoint}",
        headers={"Authorization": f"Bearer {os.getenv('PARTNER_SECRET')}"},
        json=data
    )

    result = response.json()

    if not response.ok:
        error = result.get("error", result)
        code = error.get("code", "UNKNOWN")

        if code == "RATE_LIMITED":
            time.sleep(60)
            return api_call(endpoint, method, data)

        if code == "VALIDATION_FAILED":
            print(f"Validatiefouten: {error.get('issues', [])}")

        raise Exception(f"API fout: {code} - {error.get('message')}")

    return result
```
</CodeGroup>

## Bulk operatie fouten

Bij bulk upsert operaties worden fouten per item gerapporteerd:

```json
{
  "data": {
    "successCount": 98,
    "errorCount": 2,
    "results": [...],
    "errors": [
      {
        "index": 15,
        "externalReference": "REF-015",
        "code": "VALIDATION_FAILED",
        "message": "Validation failed",
        "status": 422,
        "issues": [
          {"path": "title", "message": "Required", "code": "invalid_type"}
        ]
      }
    ]
  }
}
```

<Tip>
  Voor bulk operaties mislukt niet de hele batch als individuele items fouten bevatten. Controleer altijd de `errors` array in het antwoord.
</Tip>
