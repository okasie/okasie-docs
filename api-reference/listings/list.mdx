---
title: List Listings
api: GET /api/external/v1/listings
description: "Read the listings of the dealers your key can reach"
---

Returns the listings of the dealers your key can reach, newest change first. This includes listings those dealers created in other ways (in the Okasie dashboard or through another feed): your own listings are the ones with your `externalReference` and the `externalProvider` value you see on them.

Any valid API key can call this endpoint; no write scope is needed.

## Query parameters

Invalid values do not cause an error: they fall back to the default or are ignored.

<ParamField query="page" type="integer" default="1">
  Page number, starting at 1. Also accepted as `page_number`. A page past the end returns an empty `data` array.
</ParamField>

<ParamField query="pageSize" type="integer" default="50">
  Items per page, 1 to 200. Larger values are lowered to 200. Also accepted as `page_size` and `limit`.
</ParamField>

<ParamField query="status" type="string" default="active">
  `active`, `pending`, `sold`, `draft`, or `all` for every status. Any other value (also `inactive`) falls back to `active`. Listings that were deleted have status `inactive` and only appear with `all`.
</ParamField>

<ParamField query="updatedSince" type="string">
  Only listings changed at or after this moment, as an ISO 8601 date-time, for example `2026-11-01T00:00:00Z`. Also accepted as `updated_since`. An unparseable value is ignored.
</ParamField>

<ParamField query="locationCode" type="string">
  Only the listings of the dealer with this Dealer ID, for example `OK-00148` (exact match first, then case-insensitive). Also accepted as `location_code`.
</ParamField>

<ParamField query="dealerId" type="string">
  Only the listings of this dealer profile UUID. Also accepted as `locationId`, `profileId` and `userId`. A value that is not a UUID is ignored.
</ParamField>

<ParamField query="parentDealerId" type="string">
  Only the listings of this dealer UUID and all its child locations. Also accepted as `parentId` and `companyId`. A value that is not a UUID is ignored.
</ParamField>

A filter for a dealer outside your access returns an empty list.

## Errors

The read endpoints return a plain error body: `{"error": "<message>"}`.

| Status | Body | When |
|--------|------|------|
| 401 | `{"error": "Unauthorized"}` | Missing or unknown API key |
| 429 | `{"error": "Too many requests"}` | Rate limit reached; see the `Retry-After` header |
| 500 | `{"error": "Failed to load listings"}` | Okasie could not read the listings; retry later |
