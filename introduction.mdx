## What is Okasie?

Okasie is a Belgian used car marketplace connecting dealers with buyers. With the Partner API a stock system publishes the cars of the dealers it serves:

- **Publish and update cars** - one `PUT` per car, identified by your own reference
- **Take cars offline** - when they are sold or withdrawn
- **Send in bulk** - up to 100 cars per request
- **Read back** - the listings and dealer locations your key can reach

A key can only publish for the dealers Okasie linked to it. See [Dealer access](/authentication#dealer-access).

## Base URL

All API requests should be made to:

```
https://www.okasie.be/api/external/v1
```

## API Version

This documentation covers version 1 of the API (`/api/external/v1`). Breaking changes will be communicated in advance.
